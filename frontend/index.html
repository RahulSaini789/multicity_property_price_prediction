System Capabilities

Production-Grade, End to End

Not a Jupyter notebook. A live MLOps system with 7 layers, CI/CD, and Docker on Render.

01 / DATA
🕷️
MagicBricks Scraper
Playwright-based scraper using SERVER_PRELOADED_STATE_, 13 cities, DVC pipeline integration, priceD/caSqFt field mapping.
02 / CLEAN
🧹
City-Aware Cleaning
Grouped IQR per city×type×tier, bbox lat/lng validation, plot BHK=0, sq-yrd→sqft, India bbox filter.
03 / MODEL
🧠
XGB + LGB + CatBoost Ensemble
Optuna 100 trials, 5-fold CV, weights (0.483/0.159/0.358) tuned via secondary Optuna. 53 features.
04 / EXPLAIN
🔍
SHAP Explainability
KernelExplainer on every prediction. Top-3 drivers returned in API response. city_tier_num at 48.7%.
05 / SERVE
⚡
FastAPI + Docker + HuggingFace
Models on HF Hub Dumdigi/multicity. Downloaded at startup on Render. 123ms p50 latency.
06 / CI/CD
🚀
6-Stage GitHub Actions
lint → test (40+ cases) → model-gate (MAPE≤22%, R²≥0.82) → docker build → Render deploy → smoke-test.
